# Amazon Listing Audit Checklist

## Product Data
- [ ] SKU is unique and consistent
- [ ] Brand is consistent
- [ ] Product identifier is verified
- [ ] Product type/category is appropriate
- [ ] Required attributes are complete

## Content
- [ ] Title is readable and product-specific
- [ ] Bullets explain features and customer value
- [ ] Description is accurate and useful
- [ ] Search terms avoid unnecessary repetition
- [ ] Claims can be supported

## Variations
- [ ] Parent is non-buyable
- [ ] Child SKUs use valid variation values
- [ ] Variation theme fits the category
- [ ] Child titles and attributes are consistent

## QA
- [ ] Main image meets marketplace requirements
- [ ] Listing renders correctly after upload
- [ ] No suppression or missing-data warning remains
